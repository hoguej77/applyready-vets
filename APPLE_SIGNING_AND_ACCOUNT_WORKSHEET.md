## Signing sequence

1. Install the latest non-beta Xcode version accepted by App Store Connect at archive time.
2. Sign into Xcode with the Account Holder or a least-privileged invited developer account.
3. Register all identifiers and enable only reviewed capabilities.
4. Insert the verified Team ID and final URLs in `ios/project.yml`.
5. Regenerate the Xcode project with the reviewed project-generation command.
6. Confirm Automatic Signing selects the intended organization for the app, Share extension, widget, tests, and UI
   tests without changing bundle identifiers.
7. Run `make app-store-preflight`.
8. Build and run on an eligible physical iOS 27 iPhone.
9. Complete the signed device and StoreKit test matrix in `BETA_TEST_PLAN.md`.
10. Archive, validate, and upload only the exact build that passed the release checklist.
