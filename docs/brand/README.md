# ApplyReady Vets visual identity

## Build 17 mark

The mark combines an open doorway, a verified check, and a forward/upward
arrow. The paths beneath it represent service backgrounds converging into one
candidate-controlled career direction. It is intentionally branch-neutral.

The symbol must not be described as a VA, DoD, or military-service emblem. It
contains no government seal, branch insignia, rank, eagle, flag illustration,
or endorsement claim.

## Production files

- `ApplyReadyVetsIcon_Master_v2.png` is the retained 1,254-pixel generated
  master.
- The Xcode asset catalog contains a 1,024 × 1,024 opaque app icon and a
  512 × 512 in-app mark derived from that master.
- iOS applies the final icon mask. Do not bake rounded transparent corners into
  the source artwork.

## Generation record

The built-in image-generation tool created the master on July 29, 2026. The
prompt requested a minimal, vector-like iOS mark in midnight navy, warm white,
restrained red and civic blue, with a small gold accent; six service paths were
to converge into one doorway/check/forward-arrow symbol. It expressly excluded
text, seals, insignia, eagles, rank symbols, weapons, camouflage, flags,
watermarks, device mockups, and pre-rounded corners.

Generated art remains subject to human brand review, small-size legibility
testing, trademark clearance, and final App Store review.
