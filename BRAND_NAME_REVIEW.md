# Brand name review

Last reviewed: July 29, 2026

This is not a trademark opinion. It is a working product naming review based on preliminary web search and product strategy.

Apple says app names should be simple, memorable, easy to spell, distinctive, and no more than 30 characters. USPTO clearance, App Store search, domain search, and attorney review are still required before final launch.

## Recommendation

Use **ApplyReady Vets** as the current public working name for the veteran-first app.

Use an LLC name that supports the desired App Store developer display, such as **Jonathan Hogue Develops LLC**, or a broader umbrella such as **Hogue Career Systems LLC** if multiple products will be launched later.

## Why ApplyReady Vets now leads

- It is clearer to a first-time App Store user than the prior `MusterForward` working name.
- It says what the app does: helps veterans become application-ready.
- It keeps the veteran audience explicit without using protected VA, DoD, branch, or government marks.
- It leaves room for a later civilian sibling under an ApplyReady-style naming family.

The full Xcode target/module/folder rename is complete. `MusterForward` is retained only as naming history and as a
compatibility identifier for earlier beta data.

## Why MusterForward previously led

- It is veteran-native without using official branch, VA, DoD, or government marks.
- It suggests transition and action.
- It fits the six-branches logo concept.
- It is more memorable than HogueResMaster or MusterPath.
- Preliminary web searching found weaker conflict signals than several alternatives.

## Current shortlist

1. **ApplyReady Vets** — current public working name.
2. **MusterForward** — retired fallback and historical name.
3. **ServicePath** — best plain-language backup.
4. **FormationWorks** — best organization/licensing-friendly backup.
5. **MeritForward** — best future civilian-friendly bridge.
6. **TruthLock Careers** — best if the evidence-safety engine becomes the brand.

## Names to avoid or treat cautiously

- **CareerProof**: active AI career products appear to use this name.
- **RallyForward**: active non-career uses appear to exist.
- **SkillBridge**: too close to the official DoD SkillBridge program.
- Any name using official branch seals, VA marks, DoD marks, USAJOBS, LinkedIn, Indeed, or Workday as if affiliated.

## App Store naming package

- Name: `ApplyReady Vets`
- Subtitle: `Veteran Career Builder`
- Tagline: `From service to submitted.`
- Full paid product: `ApplyReady Vets Complete`
- Engine name: `Truth Lock Career Engine`
- Company candidate: `Jonathan Hogue Develops LLC` or `Hogue Career Systems LLC`
